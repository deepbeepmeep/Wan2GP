Model choice concepts:
- Output: what the request produces, in filters.main_output. "A portrait of a knight" is image; "a 10-second clip of waves" is video; "a jingle" is audio.
- Inputs: media the user supplies and the role each plays, in filters.inputs/capabilities. "Animate this photo" uses the image as an opening frame (image_to_video); "put this person in a cafe scene" uses it as a subject reference (reference_images); "continue this clip" needs video_continuation.
- Speciality: a strength a model declares for a kind or style of result, in specialities. "A watercolor landscape" names a style (watercolor); "pixel-art sprites" names a kind (pixel art); "a dog on a beach" names only a subject, so no speciality.
- Speed: how fast generation runs. accelerated="native" models are already fast; accelerated="profiles" models become fast by applying their recommended profile. "Use an accelerator" or "make it quick" is a speed request: it never changes which model you choose.
- Size: whether a model is a lighter or larger variant. It only breaks ties between otherwise equal candidates.
Model choice rules:
1. A named model or template is used as is; find it with wangp_models(query="<name>").
2. Otherwise read the category template, wangp_deepy_templates(tool_id="<category>"): gen_video_with_refs for video conditioned on subject identity, appearance or motion from reference images or videos; gen_video for text or start/end-frame video; gen_video_with_speech for an existing speech clip; when a supplied speech or soundtrack must be heard as it is, use a template whose media_inputs.audio includes control (a reference is imitated, not kept), such as a gen_video_with_speech template.
3. Search once if the request names a speciality or needs an input or output the template lacks: wangp_models(action="search", arguments={"filters":{"main_output":"<kind>","capabilities":[...]},"specialities":[...]}). Never page through the catalog.
4. An exact speciality match, or a model covering what the template lacks, replaces the template; otherwise keep the template.
5. Speed and size only order equally suitable results and decide acceleration. For a chosen non-template model, read its defaults and needed guidance; with the fast preference and accelerated="profiles", apply the recommended profile's settings from wangp_model(action="profiles") over the defaults.
